# Synthetic Plumbing Chain Demand Dataset

Daily data for 8 branches of a fictional plumbing franchise (Mr. Rooter–style), 2023-01-01 to 2025-12-31.
Generated by `generate_plumbing_data.py` (seed 42; re-run to regenerate or change the parameters).

## Tables and join keys

| File | Grain | Rows | Join on |
|---|---|---|---|
| `daily_demand.csv` | branch × service × day (**main forecasting table**) | ~74k | `date`, `branch_id` |
| `jobs.csv` | one completed job | ~240k | `branch_id`, `job_date` |
| `weather_daily.csv` | branch × day | 8,768 | `date`, `branch_id` |
| `marketing_daily.csv` | branch × day | 8,768 | `date`, `branch_id` |
| `calendar.csv` | day | 1,096 | `date` |
| `branches.csv` | branch | 8 | `branch_id` |

## Key columns

**daily_demand.csv**
- `calls_received` — **target**: service requests that day (true demand)
- `emergency_calls` — subset flagged emergency
- `jobs_completed`, `jobs_deferred`, `cancellations` — what capacity allowed (completed < calls when understaffed)
- `technicians_on_shift`, `avg_ticket_usd`, `revenue_usd`
- `service_type`: drain_cleaning, leak_repair, water_heater, toilet_fixture, sewer_line, burst_frozen_pipe, sump_pump, inspection_camera, repipe_remodel

**weather_daily.csv** — `temp_avg/min/max_c`, `precip_mm`, `snow_cm`, flags `is_freeze` (min ≤ −6 °C), `is_hard_freeze`, `heavy_rain` (≥ 25 mm), `heatwave`

**marketing_daily.csv** — `marketing_spend_usd`, `promo_active`

**calendar.csv** — day/week/month, `is_holiday`, `holiday_name`, `is_brown_friday`, `is_christmas_week`, `is_school_holiday`

**branches.csv** — city, state, `climate_zone`, `open_date`, `households_k`, `technicians_fte`, `avg_housing_age_yrs`

**jobs.csv** — `request_ts`, `is_emergency`, `customer_type`, `booking_channel`, `repeat_customer`, `technician_id`, `response_hours`, `duration_hours`, `invoice_usd`, `customer_rating`

## Patterns built into the data (what a good model should learn)
- Per-branch growth trend (3–10%/yr); soft dip Feb–Apr 2024
- **BR08 Charlotte opens 2024-07-01** and ramps up over ~6 months (cold-start case)
- Weekly cycle: Monday peak, Sunday trough; emergencies much flatter
- Service-specific seasonality (water heaters & frozen pipes peak in winter, sump pumps in spring, remodels in summer)
- Freeze days → burst-pipe spikes (~18× normal), with an extra spike the day pipes thaw
- Heavy rain → sewer/sump calls same day and 1–2 days later
- "Brown Friday" (day after Thanksgiving) ≈ 2.5× normal drain calls; Christmas-week bump
- Holidays cut scheduled work but not emergencies
- Marketing works with a carry-over (adstock) effect; promos give a lift
- Overdispersed (negative binomial) counts

## Data-quality issues left in on purpose
- ~0.6% missing temperatures, ~0.4% missing precipitation
- BR04 CRM outage 2025-03-10 to 03-12: `calls_received` is NaN
- `avg_ticket_usd` is NaN when no jobs completed

## Suggested setup
Forecast `calls_received` (not `jobs_completed` — that is capped by staff). Train on 2023-01 → 2025-06, validate on 2025-07 → 2025-12. Baselines: seasonal naive (same weekday last week), then Prophet/SARIMAX, then LightGBM with lag/rolling + weather + calendar + marketing features.
